Focus Flow: installable version
================================
This folder is a ready-to-host copy of Focus Flow that can be installed on a phone or computer like an app.
It saves data on the device only (no sign-in, no sharing between phones).
The version opened from its Claude link has sign-in, saving on every device and shared plans.

Host it (free, about 5 minutes), any ONE of these:
 1. Netlify Drop: go to app.netlify.com/drop and drag this whole folder in. You get an https link.
 2. GitHub Pages: put these files in a repository, then Settings > Pages > Deploy from branch.
 3. Cloudflare Pages: create a project and upload this folder.

Install:
 - iPhone (Safari): open the link, Share, Add to Home Screen.
 - Android (Chrome): open the link, menu, Install app.
 - Desktop (Chrome/Edge): install icon in the address bar.
It must be served over https (the three hosts above do this) for installing and offline use to work.
